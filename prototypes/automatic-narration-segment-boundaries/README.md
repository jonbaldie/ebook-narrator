# Prototype: Automatic Narration Segment Boundaries

Throwaway logic prototype for [Prototype Automatic Narration Segment Boundaries](https://github.com/jonbaldie/ebook-narrator/issues/11).

## Question

How should the Narration Application create Narration Segments automatically from EPUB chapters, headings, paragraphs, and text length? When may the Narrator accept, join, or split a boundary without making EPUB import feel technical?

## Run

Open `index.html` in a browser. No install step.

```bash
open prototypes/automatic-narration-segment-boundaries/index.html
```

## What to try

1. Walk through the five guided scenarios in order.
2. Change sample books and use **Combine with next part** or **Split after paragraph N**.
3. React to the proposed product decision at the bottom of the page.

## Not production

This file is a design probe only. It does not import real EPUB files and does not belong on the main product path.

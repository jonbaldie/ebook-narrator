# Triage labels

Skills use five triage roles. This table gives the GitHub label for each role.

| Skill role | GitHub label | Use |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must check the issue. |
| `needs-info` | `needs-info` | The reporter must give more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is ready for an agent. |
| `ready-for-human` | `ready-for-human` | A person must do the work. |
| `wontfix` | `wontfix` | The team will not do this work. |

Use the GitHub label in the second column when a skill names a triage role.

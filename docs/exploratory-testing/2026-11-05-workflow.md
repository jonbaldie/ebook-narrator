# Workflow prototype exploratory test

## Scope and setup

The test used commit `f30eb49b779274ce85c91051bce7db20eea0fe73` on 2026-11-05. The repository contains prototypes, not a production Narration Application. The [workflow prototype](../../prototypes/narrator-recording-workflow/README.md) uses in-memory test state. It does not import an EPUB file, record audio, save a Project, or create an export.

The test used a clean worktree, `npm ci`, Python's HTTP server, Playwright 1.52.0, and headless Chromium 136. The server used `127.0.0.1:18766`. Each replay started with a fresh page load. The browser, downloaded system libraries, npm cache, and temporary files stayed in the worktree. Playwright did not support the host's Ubuntu 26.04 version, so the test used its Ubuntu 24.04 browser build and locally extracted system libraries. The [browser script](evidence/2026-11-05/journeys.js) and [output](evidence/2026-11-05/journeys.txt) record the actions and results. To serve the prototype from the repository root, run `python3 -m http.server 18766 --bind 127.0.0.1 --directory prototypes/narrator-recording-workflow`.

## Journeys

1. **Start a Project and test the microphone.** New Project and Choose your EPUB file led to Your book is ready. Back returned to Choose your book. A second choice, Continue, Test microphone, Try again, and a second test led to the recording screen. The Back result confirms the fix for [issue 19](https://github.com/jonbaldie/ebook-narrator/issues/19). A new Project after a prior recording retained that recording, as described below.
2. **Record and review.** Record, Pause, and Stop changed the displayed state. Resume let the test continue to Stop. Browse showed the first part as recorded and the other parts as not recorded. Review, Adjust the start or end, Done, and Record again returned to part 1. The test moved the start control, but the prototype does not model or save an audio Trim. No audio effect was verified.
3. **Complete the simulated flow.** The test recorded all three parts, continued through three final checks, and reached Export complete. Reload returned to the initial state with zero saved parts. This agrees with the documented in-memory limit. The test did not create an export file or verify Final Review of audio.

## Confirmed issue

[Issue 23](https://github.com/jonbaldie/ebook-narrator/issues/23) records that a new Project keeps the prior recording state. The prototype can show a Narrator a recording from the prior Project as part of the new Project. The result does not establish any effect on real audio.

Starting from a fresh page, select Continue recording, Record, and Stop. Select My Project and New Project. Select Choose your EPUB file, Continue, Test microphone, and Yes, continue. Select My recordings and Browse all recordings. A new Project should start at part 1 with no recorded parts. Instead, it starts at part 2 with one saved part, and the list marks part 1 as recorded. Two fresh page loads gave the same result. The prototype uses the same fixed book title for both Projects. The script and output above record both replays. No existing issue or rejected report for this case was found in the tracker.

## Unresolved observation

The [earlier report](2026-10-28-workflow.md) records that Next text changes the part during a simulated recording. Stop then marks the later part as recorded. The earlier report did not establish the intended ownership of an active Take after navigation. This pass did not repeat that observation. [Issue 16](https://github.com/jonbaldie/ebook-narrator/issues/16) covers Take ownership after a boundary change, not this navigation case.

## Limits and cleanup

The native audio prototype targets macOS and Windows. This Linux host lacks the GLib, GTK, WebKitGTK, and ALSA development packages. The native prototype was not built or run in this pass. The [prior report](2026-10-28-workflow.md) records the locked build failure on Linux. The [native test results](../../prototypes/native-audio-wav-project-format/TEST-RESULTS.md) record prior macOS work and deferred Windows and device tests.

The workflow prototype has no real EPUB picker, microphone capture, playback, Project persistence, or export. Those production journeys remain untested. The final checks show simulated success without audio playback. The test cannot use them to assess the agreed Final Review.

The test registered the server before use and closed the browser in a `finally` block. The server exit trap stopped and waited for the server. After the run, port 18766 had no listener and no process used the worktree browser path. No container, image, or volume was started for this pass.
